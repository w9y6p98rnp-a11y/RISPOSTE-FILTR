# Modifica voci – istruzioni personalizzate più vincolanti

Le istruzioni inserite dall’utente per ogni voce vengono trattate come vincolanti dal prompt AI.

- “Risposte più lunghe” viene interpretato come aumento evidente; quando il contesto lo permette, circa 25–45 parole per risposta.
- “Risposte più corte” mantiene le risposte brevi.
- Le 5 risposte dello stesso stile devono avere idee, aperture, struttura, ritmo e vocabolario differenti.
- Le risposte vengono confrontate con quelle precedenti per evitare ripetizioni e quasi-parafrasi.
- Il nome visualizzato resta solo un’etichetta UI; l’AI continua a usare gli ID tecnici delle voci.
