# RispostaFlirt — registrazioni vocali

Aggiunta la possibilità di allegare una registrazione vocale insieme allo screenshot.
- Pulsante "🎙️ Aggiungi registrazione vocale".
- Supporto ai principali formati audio iPhone/WhatsApp.
- Trascrizione automatica tramite Gemini 3.5 Transcribe.
- La trascrizione viene mostrata sotto la registrazione.
- La trascrizione viene passata all'AI insieme allo screenshot per generare le risposte.
- Il limite lato browser per questa versione è 12 MB per registrazione.
- Quando il messaggio viene salvato nella conversazione, la trascrizione viene conservata come testo anche per la sincronizzazione dell'account.


## Versione 2 - vocale integrato
Il pulsante separato “Aggiungi registrazione vocale” è stato rimosso. Il pulsante “Aggiungi screenshot” accetta anche un file audio e può ricevere più file: se vengono selezionati uno screenshot e il vocale, l'app li riconosce automaticamente, trascrive il vocale e usa la trascrizione insieme allo screenshot per generare le risposte.

Nota: una vera immagine screenshot non contiene il contenuto audio del vocale. Per trascrivere un vocale serve il file audio reale; l'app ora lo gestisce dallo stesso pulsante, senza un secondo pulsante dedicato.
